# Moviq

**Moviq** is a simple and engaging movie discovery web app that lets users explore movies effortlessly.  
View trailers, read descriptions, check ratings, and see release dates — all in one clean, responsive interface.

---

##  Features

-  Watch official movie trailers  
-  Read detailed movie descriptions  
-  View ratings and release dates  
-  Search for movies easily  
-  Responsive design for all devices  
-  Built with simplicity and speed in mind  

---

## Built With

- **HTML5**  
- **CSS3 / Bootstrap**  
- **JavaScript (Fetch API)**  
- **TMDB API** – for movie data and trailers
